# 클린뉴스&맥락번역기

### ▶ [바로 써보기](https://flax-six-41.vercel.app/)

뉴스 기사를 **3줄요약 · 어휘풀이 · 사실/의견 분리**로 다시 읽어 주는 웹 도구입니다.

청소년·청년층의 문해력 저하와, 가짜 뉴스로 인한 확증편향을 함께 겨냥해 만들었습니다.
기사를 "요약해서 빨리 읽게" 하는 데 그치지 않고, **어디까지가 사실이고 어디부터가 누군가의
판단인지** 눈에 보이게 하는 것이 목표입니다.

별도 빌드나 설치 없이 정적 페이지로 동작하며, 분석 기록 저장에는 Supabase를 사용합니다.

## 무엇을 해 주나

| 기능 | 내용 |
|---|---|
| **3줄 요약** | 기사에서 핵심 문장 3개를 원문 그대로 뽑아냅니다 |
| **어휘 풀이** | 어려운 한자어·전문용어를 중학생 눈높이로 풀고, 본문에서 실제로 쓰인 문장을 함께 보여줍니다 |
| **사실 / 의견 분리** | 확인해 볼 핵심 사실과, 기사에 담긴 판단·전망을 나눠서 보여줍니다 |
| **신뢰도 체크리스트** | 출처 표기, 익명 출처, 수치 유무, 자극적 표현, 의견 비중을 점검합니다 |
| **분석 기록** | 분석할 때마다 통계를 쌓고 CSV·JSON으로 내보낼 수 있습니다 |

다루는 분야는 **스포츠 · 경제 · 정치 · 연예 · 과학** 다섯 가지입니다.

## 사용법

### 1. 기사 넣기

두 가지 방법이 있습니다.

- **본문 붙여넣기** (권장) — 기사 제목과 본문을 그대로 복사해 붙여넣습니다. 기자 이름,
  입력 시각, `ⓒ 무단전재 및 재배포 금지`, 관련기사 목록 같은 군더더기는 자동으로 걸러냅니다.
- **링크 붙여넣기** — 주소를 넣으면 본문을 자동으로 가져옵니다. 다만 **브라우저 보안 정책이나
  언론사 설정 때문에 실패할 수 있습니다.** 실패하면 화면에 원인이 표시되고, 그때는 본문을
  직접 붙여넣으면 됩니다.

### 2. 분야 고르기

고른 분야의 전용 용어 사전이 먼저 적용됩니다.

### 3. 분석하기

결과는 아래로 이어지는 화면에서 순서대로 확인할 수 있습니다.

## 어떻게 분석하나

키 없이도 **내장 규칙 엔진**으로 전부 동작합니다. 인공지능 호출 없이 브라우저 안에서 계산합니다.

**3줄 요약** — 문서 전체의 단어 빈도, 문장 위치, 제목과 겹치는 정도로 점수를 매겨 상위
문장을 고릅니다. 서로 60% 이상 겹치는 문장은 제외해 같은 말이 반복되지 않게 했습니다.

**어휘 풀이** — 분야별 사전(경제 19 · 정치 17 · 과학 16 · 스포츠 13 · 연예 12)과 기사에
공통으로 쓰이는 한자어 23개를 담고 있습니다. 영문 약어는 자동으로 찾아냅니다.

**사실 / 의견 분리** — 문장을 전부 늘어놓지 않고, 기사 전체 맥락에서 **중요한 것만** 골라
보여줍니다.

- *확인해 볼 핵심 사실* — 검증 가능한 것(숫자·출처가 있는 문장)을 우선해 고르고,
  **어떻게 확인하면 되는지** 함께 알려줍니다.
- *기사에 담긴 판단·전망* — 사실처럼 쓰였지만 실은 판단인 문장을 골라,
  **누구의 판단인지**(기사 작성자 / 전문가 / 시장 / 인용된 인물) 밝힙니다.

판단 근거가 된 표현(`전망이`, `지적됐`, `분수령` 등)은 문장 안에 표시되어, 읽는 사람이
스스로 구분하는 법을 익히도록 했습니다.

**본문만 골라내기** — 링크로 가져오든 붙여넣든, 사이드바의 다른 기사 제목이나 추천기사
목록이 분석에 섞이지 않도록 세 단계로 걸러냅니다. 링크 밀도로 목록을 판별하고, `관련기사`
같은 표시에서 뒤를 잘라내고, 서술문이 이어지는 구간만 남깁니다.

## 알아둘 점

**신뢰도 체크리스트는 글의 *형식*만 봅니다.** 내용의 진위를 판정하지 않습니다. 출처를 잘
밝힌 기사도 틀릴 수 있고, 그 반대도 마찬가지입니다. 항상 원문과 다른 매체를 함께 확인하세요.

**어디로 무엇이 나가는지**

- 기본 분석 계산은 브라우저 안에서 이뤄집니다. 분석을 마치면 기사 본문과 분석 결과 전체가
  Supabase에 기록됩니다(설정 전이거나 연결 실패 시 브라우저에 임시 저장).
- **링크 자동 가져오기**를 켜면 주소가 외부 수집 서비스로 전송됩니다. (기본 켜짐, 끌 수 있습니다)
- **AI 정밀 분석**을 쓰면 기사 본문이 Anthropic API로 전송됩니다. (기본 꺼짐)

**분석 기록**은 Supabase 설정 시 데이터베이스에 저장됩니다. 별도 회원가입 화면 없이 익명 사용자
세션으로 기록을 구분하며, Supabase 연결 전이나 일시적인 장애 때는 브라우저에 임시 저장됩니다.

## Supabase 연결

1. Supabase 프로젝트의 SQL Editor에서 `supabase/schema.sql`을 실행합니다.
2. Authentication → Providers → Anonymous Sign-Ins를 활성화합니다.
3. `index.html`의 `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`에 프로젝트 URL과 publishable key를
   입력합니다. 기존 프로젝트의 legacy anon key도 사용할 수 있습니다.

테이블에는 RLS가 적용되어 익명 사용자도 자신의 분석 기록만 조회·추가·삭제할 수 있습니다.
분석이 끝나면 DB 저장 후 분석 기록의 총 건수, 평균 의견 비중, 분야별 횟수와 최근 기록이
즉시 다시 계산됩니다. `service_role` 또는 secret key는 브라우저 코드에 넣으면 안 됩니다.
공개 배포에서는 익명 계정 남용을 막기 위해 Supabase Auth의 CAPTCHA 또는 Cloudflare Turnstile도
설정하는 것이 좋습니다.

## AI 정밀 분석 (선택)

고급 설정에 Claude API 키를 넣으면 훨씬 정확해집니다. 호출이 실패하면 자동으로 규칙
엔진으로 넘어가므로 분석이 멈추는 일은 없습니다.

> ⚠️ 브라우저에 키를 넣는 방식은 **개인 실습용까지만** 쓰세요. 키가 그대로 노출됩니다.
> 실제로 서비스할 때는 서버(백엔드)를 두고 그쪽에서 호출해야 합니다.

## 데이터 내보내기

분석할 때마다 아래 스키마로 기록이 쌓입니다. 그대로 데이터베이스 테이블로 옮길 수 있게
설계했습니다.

| 필드 | 설명 |
|---|---|
| `id`, `analyzed_at` | 식별자, 분석 시각(ISO 8601) |
| `category` | 분야 |
| `title`, `url` | 기사 제목, 주소 |
| `article_text` | 분석한 기사 본문 |
| `char_count`, `sentence_count` | 본문 길이, 문장 수 |
| `fact_count`, `opinion_count`, `quote_count` | 사실·의견·인용 문장 수 |
| `opinion_ratio` | 의견 비중 (0~1) |
| `vocab_count` | 풀이한 어휘 수 |
| `engine` | 규칙 기반 / AI 정밀 분석 |
| `summary`, `vocab` | 3줄 요약, 어휘 풀이 결과(JSON) |
| `key_facts`, `key_opinions` | 핵심 사실·판단 결과(JSON) |
| `checks` | 신뢰도 체크리스트 결과(JSON) |

`분석 기록` 화면에서 **CSV · JSON**으로 내려받을 수 있습니다.

## 실행 · 배포

### 내 컴퓨터에서

`index.html`을 브라우저로 열면 끝입니다. 빌드도 설치도 없습니다.

```bash
start "" "index.html"     # Windows
open index.html           # macOS
```

### 웹에 올리기

정적 사이트이므로 어디에나 올라갑니다. 저장소를 Vercel·Netlify·GitHub Pages에 연결하면
바로 배포됩니다. 이 저장소는 Vercel에 연결돼 있어, `main`에 푸시하면
[flax-six-41.vercel.app](https://flax-six-41.vercel.app/)에 자동으로 반영됩니다.

> 정적 호스팅은 루트 주소로 들어오면 `index.html`을 찾습니다. 파일 이름을 바꾸면
> 404가 뜨니 주의하세요.

배포된 사이트에서는 **링크 자동 가져오기가 막힐 수 있습니다.** 본문 붙여넣기는 문제없이
동작합니다.

## 파일 구성

```
index.html            프로그램 전체 (HTML + CSS + JavaScript, 의존성 없음)
robots.txt            검색 로봇 접근 정책과 사이트맵 위치
sitemap.xml           Google Search Console 제출용 사이트맵
DESIGN.md             디자인 시스템 분석 — Tesla
DESIGN.md_apple.md    디자인 시스템 분석 — Apple (현재 화면의 기준)
```

화면은 `DESIGN.md_apple.md`를 따릅니다. 명암이 교차하는 전면 타일, 17px 본문,
Action Blue 단일 강조색, 알약형 CTA가 핵심입니다. 디자인을 손볼 때는 이 문서의
토큰 이름을 그대로 참조하면 됩니다.

## 만든 이유

빠르게 읽히는 요약은 이미 많습니다. 이 도구가 하려는 일은 그 반대에 가깝습니다 —
**한 번 더 의심하게 만드는 것**입니다. "전문가들은 ~할 것으로 평가했다" 같은 문장이
사실이 아니라 누군가의 판단이라는 걸 알아차리는 순간부터, 뉴스는 다르게 읽힙니다.
